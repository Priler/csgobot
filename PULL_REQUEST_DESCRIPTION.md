# Pull Request: Ultimate Hybrid CS Bot v9.0

## 📋 Описание
Этот PR добавляет **ULTIMATE HYBRID CS BOT v9.0** - инновационное слияние автономной системы обучения на основе чата с профессиональной архитектурой обнаружения YOLO.

## ✨ Основные особенности

### Из оригинального кода (v8.0)
- ✅ **Система обучения на основе чата** - бот изучает команды команды (купить, атаковать, защищать, рвать, снайпер)
- ✅ **Автоматическая покупка оружия** - интеллектуальный выбор в зависимости от денег
- ✅ **Автономное движение и прицеливание** - независимая игровая механика
- ✅ **SendInput контроллер Windows** - прямой контроль ввода
- ✅ **Сохранение памяти** - персистентное хранилище для обучения

### Из Priler/csgobot
- ✅ **YOLO v8 детектирование нейронной сети** - профессиональное обнаружение
- ✅ **Архитектура с несколькими процессами** - оптимизированная обработка
- ✅ **Определение команды** (CT vs T) - различие врагов и товарищей
- ✅ **FOV-базированные расчеты прицеливания** - реалистичная математика
- ✅ **Продвинутая система логирования** - отладка и мониторинг

### 🆕 Новые гибридные функции
- 🎯 **Двойной режим детектирования** (YOLO + HSV цвет с резервным вариантом)
- 🧠 **Тактические решения на основе чата** - бот учится у команды
- 🎬 **Предсказание движения** - экстраполяция позиций движущихся целей
- ⚡ **Автоматическая загрузка модели** - обработка ошибок с корректным откатом
- 🔧 **Полная интеграция** - бесшовное объединение обоих проектов

## 🎮 Управление

| Клавиша | Действие |
|---------|---------|
| **F8** | Запуск/Остановка бота |
| **F** | Пауза/Возобновление |
| **ESC** | Выход из программы |

## 🔧 Использование

### Запуск с цветовым детектированием (по умолчанию)
```python
python bot_ultimate_v9.py
```

### Запуск с YOLO детектированием
Отредактируйте строки в конце файла:
```python
USE_YOLO = True
YOLO_MODEL_PATH = "./yolov8/best.pt"

bot = HybridCSBot(use_yolo=USE_YOLO, yolo_model_path=YOLO_MODEL_PATH)
```
